# Template Scene CPR - Unity 6

## Isi
- Editor script untuk membuat scene `Scene_CPR`
- Placeholder background, pasir, laut, Lifeguard, dan NPC
- Canvas dengan panel misi, dialog, simulasi CPR, dan hasil
- EventSystem dan Main Camera

## Cara menggunakan
1. Ekstrak folder ini.
2. Salin folder `Assets/CPRTemplate` ke folder `Assets` project Unity kamu.
3. Buka project di Unity dan tunggu compile selesai.
4. Pastikan TextMeshPro sudah tersedia. Jika diminta, pilih **Import TMP Essentials**.
5. Di menu Unity, pilih **Tools > CPR > Generate Starter Scene**.
6. Scene akan dibuat dan disimpan sebagai `Assets/Scenes/Scene_CPR.unity`.

## Catatan
- Ini adalah kerangka scene dan placeholder, bukan gameplay CPR yang sudah berfungsi penuh.
- Ganti placeholder karakter/background dengan sprite milikmu.
- Hubungkan tombol ke script gameplay setelah alur scene ditentukan.
- Konten CPR dalam game sebaiknya mengikuti panduan resmi pertolongan pertama dan tidak menggantikan pelatihan tersertifikasi atau instruksi operator darurat.
