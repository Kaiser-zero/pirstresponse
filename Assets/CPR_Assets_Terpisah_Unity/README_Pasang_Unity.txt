ASET CPR PANTAI – PNG TERPISAH UNTUK UNITY

Folder Lifeguard: pose berdiri, jalan, lari, berlutut, dan menolong.
Folder NPC_Korban: pose berdiri dan terbaring.
Folder Background: panorama pantai dan laut/langit.
Folder Atlas_Asli: lembar aset utuh.

Pemasangan:
1. Salin folder Lifeguard, NPC_Korban, dan Background ke Assets/CPRAssets.
2. Pilih PNG di Unity. Set Texture Type = Sprite (2D and UI), Sprite Mode = Single.
3. Klik Apply, lalu drag sprite ke Scene atau gunakan di Sprite Renderer.

Catatan: PNG mempertahankan transparansi atlas. Pose menolong adalah pose statis, bukan animasi CPR lengkap. Periksa hasil crop di Unity dan sesuaikan ukuran/posisi. Materi CPR harus divalidasi dengan panduan pertolongan pertama resmi.
