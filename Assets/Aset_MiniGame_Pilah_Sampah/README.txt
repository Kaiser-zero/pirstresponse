ASET MINI-GAME PILAH SAMPAH — UNITY 2D

Isi folder:
- 01_AssetSheet_Dekorasi_dan_Sampah.png
  Lembar referensi aset sampah organik/anorganik, dekorasi pantai, dan efek.
- 02_AssetSheet_UI_dan_Sampah.png
  Lembar referensi UI, ikon kategori, tempat sampah, skor, feedback benar/salah, dan layar hasil.
- 03_Background_Pasir_1920x1080.png
  Background pasir saja, tanpa laut, untuk scene mini-game.

PENTING:
- Dua file AssetSheet adalah lembar aset gabungan, bukan sprite transparan yang sudah dipisahkan.
- Untuk mengambil gambar satu per satu di Unity: pilih file sheet di Project > Inspector > Sprite Mode: Multiple > Apply > Sprite Editor > Slice (atau potong manual) > Apply.
- Karena lembar gabungan memiliki latar, untuk penggunaan sprite yang benar-benar terpisah/transparan, tiap objek perlu dipotong dan background-nya dibersihkan terlebih dahulu.
- Background pasir dapat langsung diimpor sebagai Sprite (2D and UI) dan dipasang sebagai gambar latar. Atur Pixels Per Unit dan ukuran sesuai kamera/Canvas.
