BEACH GAME - LEVEL COMPLETE UI ASSETS

All files are separate PNG sprites with transparent backgrounds.
Suggested Unity import:
1. Copy this folder into your Unity project's Assets folder.
2. Select each PNG in Unity.
3. Set Texture Type = Sprite (2D and UI), Sprite Mode = Single.
4. Click Apply.
5. Use UI > Image and assign the desired sprite in Source Image.

Suggested use:
- Trophy and Title: menu header.
- Score_Panel: place a separate TextMeshPro text over the blank center area for dynamic score.
- Message_Panel: place a separate TextMeshPro message over its center.
- Star_Active / Star_Inactive: use three UI Images and swap sprites based on score.
- Button_Kembali_ke_Pantai: use as a visual Image, then place a transparent Unity Button over it (or create a Button and assign this sprite).
- Wave, Cloud, Beach_Island, Seagull: optional decorations.

Note:
The score panel and message panel are blank on purpose so Unity TextMeshPro can display dynamic text.
The title and button sprites include their decorative lettering.
