PAKET ASET - PASANGKAN SIMBOL KESELAMATAN (UNITY 6 / 2D)

ISI FOLDER
- Background: background pantai landscape.
- Cards: 12 kartu (6 pasangan) untuk memory matching.
- UI: judul, panel waktu/skor/petunjuk, tombol, ikon, bintang, panel hasil.
- Characters: 5 pose/ekspresi maskot.
- Props: dekorasi pantai.
- Spritesheet: gambar sumber sebagai referensi.

CATATAN PENTING
Aset ini merupakan paket visual awal. Beberapa potongan UI/props diambil dari satu lembar gambar; latar kotak-kotak pada sebagian potongan mungkin masih terlihat karena pola tersebut sudah menyatu pada gambar sumber. Kartu-kartu sudah berupa tile persegi panjang yang siap dipakai.

PENGATURAN IMPORT UNITY
1. Ekstrak ZIP ke folder Assets/MatchingSimbol/.
2. Pilih PNG -> Inspector -> Texture Type: Sprite (2D and UI).
3. Untuk Background, set Sprite Mode: Single; Pixels Per Unit boleh 100.
4. Untuk kartu dan UI, gunakan Sprite (2D and UI), Sprite Mode: Single.
5. Background pasang pada SpriteRenderer atau UI Image, lalu sesuaikan ukuran dengan Canvas/orthographic camera.
6. Buat prefab kartu dari salah satu file Kartu_*.png; duplikat menjadi 12 kartu.

PASANGAN KARTU
P3K, Pelampung, Dilarang Berenang, Telepon Darurat 119, Peringatan Bahaya, Titik Kumpul.

Paket ini berisi aset gambar, belum termasuk script gameplay Unity atau scene .unity.
